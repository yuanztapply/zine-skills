# 素材、原文与版式记录

用于实际取材、引句替换、字体审计与局部色版；这些是册外工作记录，不排进无引注的刊物。按项目规模选 JSON、表格或简明文本，不搭建批量爬取系统。

## 来源索引

| 类型 | 最少需要记录 |
| --- | --- |
| 影片事实 | 正式片名／年份／导演／版本标识、核实字段、来源页面、查询日期；冲突值与版本区别 |
| 引文 | 稳定 ID、作者、作品、出版／翻译版本、原句、词数、页码或约略时段、实际链接、阅读范围、正文用途 |
| 图片 | ID、来源页面、实际文件链接、本地文件、发布方／已知署名、尺寸、类型、画面内容、候选／入选、获取与使用状态 |
| 图像处理 | 原图与衍生图分别存放、工具、完整提示词、编辑选区、原样保留的区域、实际检查结果、本版页码 |
| 字体 | 家族／实际字重、文件、来源及许可、语言覆盖、正文／片名／页码的用途、实际回退与嵌入结果 |
| 页序 | 每页任务、图像 ID、引文 ID、阅读顺序、视觉重心、与邻页的关系、成品及裁边后尺寸 |

未知署名与许可写未确认；不以网站名称替代具体文章链接，不把预览图说成已获得高清原图。用户回忆中的场景不因此成为已验证影片镜头或放映现场影像。

## 文字登记与段落审计

逐条存原文，另存实际显示文字。只允许已记录的变化，如去除排版换行、合并行间断词，或用户明确要求删除的句点；不能暗改大小写、主语、语气或词序。

同一条原文可自动换行，不能靠大空隙把未完成句子变成多个“新段”。段落记录可包含页码、来源 ID、原句、显示文本、实际行列表、基线和字号。核对自然大写起首、完整句边界和连续行距；句末在另一行并不等于截句。

遇到小写开头的从句摘录，先回原著寻找合适的完整句；若没有，保留实际缺口并调整选文，不生成新句或默默改首字母。非连续引文保留删节记号。第一人称是谁，在册外标清。

来源替换时更新正文、文字登记、来源表、页码、预览和交付包；不要把旧句留在当前来源表里与新句混用。不要打包完整版权图书、整篇论文或仅供内部核验的整页扫描来充当必要来源清单。

## 真实图像联系图与配色

现有 `scripts/extract_palette.py` 仅对已核实的本地图片制作联系图和候选色板。先运行 `--help`，不要覆盖原始素材。其像素频率不是叙事重要性，不代表全片色彩；海报与剧照应分别判断。

编辑要另写“哪张图／哪个实体区域 → 什么色 → 承担什么页面角色”。保留原片的冷暖、明暗关系；若因用户选题使用红黄等编辑色，明确这是色版处理而非摄影原色。无需每页全部用色，也无需每张图都染色。

## 局部色版与人物保护

1. 检查真实原图，再用当前环境合适的图像编辑工具。提示词锁定人物身份、数量、姿态、画面文字、完整构图和只允许改变的区域。
2. 原图作底，衍生色版作独立层。需要精确保护时，用可编辑遮罩仅显示墙面、座席等颜色区域，再恢复原始人物或档案字样。
3. 遮罩边缘贴真实轮廓。粗糙的矩形人物保护区会变成灰补丁；墙面若在真实人头上方被一条斜线截断，仍像凭空色块。需要修轮廓，而不是再贴装饰掩盖。
4. 多个色版选区相交时，检查合并／填充规则。PDF 与 SVG 必须一致；错误的奇偶填充可能把交叠处挖成缺色孔。
5. 全图红色调等整体处理与“只染背景”不同，按用户最新指令执行；不要用原始灰色人脸保护层把全图色调要求抵消。
6. 真正黑白灰要求时，最终检查 RGB 通道是否一致，不能仅凭看起来偏灰便声称中性灰。

处理后的图仍记录为“真实原图的编辑衍生图”；不能把 AI 重绘或色版称作未经处理的实际剧照，也不能声称原图可下载就已获授权。

## 裁切与正常尺寸检查

先改变源图窗口／对齐位置，使人物离边；既不要截头、截脚，也不要把邻近人物的肩或身体碎边带进来。裁切参数依当前源图尺寸和成品比例重算，不复制别片的像素坐标或对齐系数。

正文绕图必须保持读序。标题、文字、图像边缘可以不齐，但错位需有明确对象，不靠随机倾斜制造风格。最终以真实尺寸检查字的可读性；高 DPI 导出不会提高原始剧照的有效分辨率。
