# 社交图文草稿

只在用户明确要求时操作平台。zine 制作授权不包含登录、上传或发布；“网页已登录”说明可用状态，不是扩大扩展权限的授权。

## 准备

- 从最终 PDF 导出完整页面图片；默认按页序上传，不用带工具栏的屏幕截图。
- 默认标题为原著 title，保留原文拼写；不追加未要求的营销正文、话题或 AI 总结。
- 先读取实际平台当前的图片数量、格式、标题长度与裁切行为。不要写死 Threads／小红书的历史限制。
- 优先使用单页；限图时可考虑相邻跨页组合或分组，但须保持完整与可读。无法兼顾时把具体限制与可选方案交给用户，不擅自删页或截断书名。

## 操作边界

优先用足够完成任务的连接工具；否则使用当前环境支持的浏览器操作，接续用户已登录的正确账户。不要从其他窗口或账号猜测状态。

**默认编辑好后停在发布前。** 如果用户本次明确要求只保存草稿，不点击“发布／Post／投稿”，也不通过确认对话框间接完成发布。用户以后明确授权发布时，再按该次授权和工具规则执行。

图片上传是对指定平台的传输，只上传用户指定的 zine 文件。不要把文件选择器里的其他文档一起选中。

若直接上传被扩展权限阻止，先考虑已支持的原生文件选择器等不增权路径；不要自行开启文件 URL、读取所有站点或其他新权限。确需扩权才能继续时，说明具体权限与原因并请求授权。不要把重复失败说成已上传。

遇到 UI 卡顿或选择失效时，重新观察当前状态；不连续重试陈旧元素、不盲打快捷键，尤其不让 Enter 落到发布按钮上。

## 验证与交接

- 核对标题、图片数、从封面到封底的顺序、完整比例与当前账户。
- 若是草稿任务，确认编辑框或草稿条目确实存在，按工具要求保留交接页面及截图；最终说明“已编辑、未发布”。
- 没有验证成功的部分如实说清。导出图片、填好标题、打开上传入口、完成草稿、实际发布是不同状态。
- 用户表示已自行发布时停止操作。用户的完成报告可以记录为“用户已自行发布”，不转述成 agent 完成了发布或已独立核验。
